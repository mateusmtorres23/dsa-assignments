# Data Structures and Algorithms Assignments

A collection of assignments completed during my Data Structures and Algorithms course at Universidade de Pernambuco (UPE).

The exercises were implemented in Python and cover topics ranging from programming fundamentals to classical data structures, algorithms, graph traversal, and complexity analysis.

## Topics

- Algorithmic problem solving
- Arrays and linked lists
- Stacks
- Searching and sorting algorithms
- Hashing
- Recursion
- Trees and Binary Search Trees
- Graphs and graph traversal
- Time and space complexity

## Assignments

The repository is organized into individual assignment directories. Each directory contains its own instructions, implementations, and automated tests.

The assignments use **Pytest** for automated testing and **Flake8** for code quality checks.
